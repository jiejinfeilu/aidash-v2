# AiDash 二期改造计划（v2）

> 版本：v2 计划（2026-08-13）
> 依据用户新需求整理，实施时按阶段逐步进行，每阶段完成由用户验证。
> 进度：阶段 1（版式引擎 + 混合自适应）✅ ｜ 阶段 2（手机版式选择器）✅ ｜ 阶段 3（名言实时联网 + 每日条数可配置）✅ ｜ 阶段 4（网络优化：jsDelivr 数据加速 + 多后端自动切换 + Vercel 双入口）✅ ｜ 阶段 5 核心（手机 Canvas 本地生成 + 离线预览 + 保存图片 + 立即刷新适配）✅ ｜ 阶段 6 提前完成（推送间隔/起始小时手机可配 + 立即推送接口）✅ ｜ 接下来：阶段 7（回归测试与部署）。

## 一、需求清单

1. **版式改造**：仪表盘图改为**竖屏左右两栏**（仿参考图）；另提供**横屏版式**（3~4 个区块，左右板块高度相同，最后一块在下方合并左右）；整体风格改为**星际驾驶舱仪表盘**风格。
2. **手机版式选择**：手机 App 里可自由选择竖屏/横屏两种版式，选项带**预览**。
3. **名言系统**：每日名言**自动更新、多样化**，以**中国古风名言**为主。
4. **网络优化**：GitHub / Vercel 在国内不稳定，需要更优方案（加速数据读取 + 多入口自动切换）。
5. **离线模式**：离线也能编辑，联网后**自动同步**；离线时手机可直接**生成仪表盘图、全屏预览、保存图片**。
6. **推送频率**：自动更新频率改为**每 4 小时**更新并发送。

## 二、分阶段实施计划

### 阶段 1：版式与视觉引擎（核心改造）

**做什么**：重构 `scripts/generate_image.py`
- 新增两套布局：
  - **竖屏双栏**（1072×1448）：顶部大时钟横贯，下方左右两栏分布模块，两栏高度对称，仿参考图；
  - **横屏驾驶舱**（1920×1080，可配置）：上方左右两个等高区块 + 下方一个合并左右的全宽区块，共 3~4 个区块；
- 新增**星际驾驶舱风格**：深色底、荧光描边（青色/绿色）、四角括号、等宽数字字体、仪表盘元素（进度弧线、刻度线、扫描线）；Kindle 灰阶下依然清晰（白字深底高对比）；
- 保留原"经典单栏"风格作为备选；
- `data.json.settings.layoutPreset` 控制选择：`portrait_dual`（竖屏双栏）/ `landscape`（横屏）/ `classic`（经典）。

**产出**：竖屏 + 横屏两张预览图，供用户确认风格后再继续。

### 阶段 2：手机版式选择器

**做什么**：改 `web/index.html`
- 设置页新增"仪表盘版式"：两张预览卡片（用 CSS 画的版式示意图），点选后保存到 `data.json.settings.layoutPreset`；
- 手机端可随时切换，次日推送生效。

### 阶段 3：名言系统（实时联网更新）

**做什么**：
- **实时联网获取**：每次生成仪表盘/打开 App 时，从免费名言接口拉取最新古风名言：
  - 首选：一言（hitokoto，`v1.hitokoto.cn`，诗词/哲学分类）；
  - 兜底：今日诗词（jinrishici.com）；
  - 离线兜底：内置 60+ 条中国古风名言库（论语、老子、庄子、唐诗宋词、苏轼、曾国藩等），按日期轮换；
- 获取到的名言**缓存到本地**（Python 存 `quotes.json`，手机存 localStorage），下次离线也能显示；
- 手机 App 支持**自定义名言**（存到 `data.json.customQuotes`）与**内置古风库**，都支持"立即显示"指定某条今日生效；轮换规则为**每天前 2 次显示自定义（按库循环），之后联网，联网失败用内置兜底**；
- 仪表盘"每日一言"模块与手机"仪表盘"Tab 显示同一条今日名言。

### 阶段 4：网络优化（国内可访问性）

**做什么**：
- 数据读取改用 **jsDelivr CDN**（`cdn.jsdelivr.net/gh/用户名/aidash@main/data.json`）为第一优先，GitHub raw 为备用——jsDelivr 国内通常更快更稳；
- 前端 API 调用支持**多个后端地址自动切换**（设置页可填主/备地址，超时自动换下一个）；
- Vercel 项目同时托管 `web/` 静态文件，得到**第二个 App 入口**（`https://aidash-seven.vercel.app/web/`），与 GitHub Pages 互为备用；
- 前端启动时自动探测可用入口。

### 阶段 5：离线模式与手机本地生成

**做什么**：
- 强化 Service Worker 缓存（App 外壳 + 最近一次数据 + 最近一次天气/热榜）；
- **离线编辑**：待办/倒计时/笔记在无网时照常编辑，标记"待同步"；
- **自动同步**：联网后自动把待同步内容推送到云端（本地最新为准，防覆盖）；
- **手机端仪表盘生成器**：新增"仪表盘"Tab，用 **Canvas 在手机本地绘制**今日仪表盘（数据来自本地缓存，不依赖网络），支持：
  - 竖屏/横屏两种版式实时生成；
  - 全屏预览；
  - 保存图片到手机（下载/长按存相册）。

### 阶段 6：更新频率（手机可配置）

**做什么**：
- `daily_push.yml` 改为**每小时运行一次**（cron `0 * * * *`），运行时读取 `data.json.settings`：
  - `updateHours`（推送间隔，默认 4）；
  - `pushHour`（起始小时，默认 8，即北京 08:00）；
  - 满足"当前小时 = pushHour + N×updateHours"才真正生成并推送，否则直接跳过（不耗邮件）；
- `feeds.yml` 改为每小时抓一次热榜（cron `0 * * * *`）；
- **手机 App 设置页新增"自动推送"**：可填"间隔小时数"（如 4/6/12/24）和"起始小时"，保存后写入 `data.json.settings`，下次定时任务自动按新频率执行；
- 默认 4 小时 = 每天 6 次推送；填 24 即回到每天一次。

### 阶段 7：回归测试与收尾

- 本地生成两种版式图片，检查 1072×1448 / 1920×1080、中文不乱码、布局正确；
- 手机端：版式切换、离线编辑、自动同步、Canvas 生成预览、保存图片；
- 工作流：手动触发一次，确认 4 小时定时生效、名言变化；
- 更新 README 与学习路线图（新增 Canvas/离线同步等知识点）。

## 三、假设与默认值

| 项 | 默认值 |
|---|---|
| 横屏尺寸 | 1920×1080（16:9，可在 data.json 调整） |
| 竖屏尺寸 | 1072×1448（Kindle 不变） |
| 名言来源 | 实时接口（一言/今日诗词）+ 本地缓存 + 内置 60+ 古风库兜底 + 用户自定义优先 |
| 离线天气/热榜 | 用最近一次缓存；无缓存时显示占位 |
| 同步策略 | 本地编辑优先，联网自动推送；云端仅作备份与每日推送数据源 |
| 推送频率 | 默认 4 小时/次（手机设置可改间隔与起始小时） |
