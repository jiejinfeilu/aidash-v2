# AiDash v2 部署手册（新仓库 aidash-v2）

> 目标：把 v2（新版仪表盘）部署成**独立项目**，旧版 `aidash` 原样保留。
> 完成后：新网页 `https://jiejinfeilu.github.io/aidash-v2/web/`（或 Vercel 入口），Kindle 推送只由 v2 负责。

## 第 1 步：创建新 GitHub 仓库 aidash-v2

- [ ] github.com → `+` → New repository → 名称 `aidash-v2` → Public → 创建（不勾 README）
- [ ] 仓库 Settings → Pages → Deploy from a branch → main / (root) → Save
- [ ] 先建一个 `README.md`（让 main 分支出现）：Code → Add file → Create new file → 内容 `# AiDash v2` → Commit
- [ ] 创建**新 Token**：头像 → Settings → Developer settings → Fine-grained tokens → Generate new token
  - 名称 `aidash-v2-write`，90 天
  - Repository access → Only select repositories → `aidash-v2`
  - Permissions：**Contents → Read and write**，**Actions → Read and write**（两个都要！后者用于"立即推送"）
  - 生成后复制保存到记事本
- [ ] 仓库 Settings → Actions → General → Workflow permissions → Read and write → Save

## 第 2 步：上传文件

- [ ] Code → Add file → Upload files，把本机 `aidash-v2` 文件夹里的内容拖进去（**不要拖 aidash-v2 文件夹本身**）
- [ ] 记得显示隐藏文件（查看 → 隐藏的项目），确保 `.github`、`.env.example`、`.gitignore` 都在
- [ ] 如果 `.github` 没传上去：用 Create new file 手动创建 `.github/workflows/feeds.yml` 和 `.github/workflows/daily_push.yml`（内容见本机文件）
- [ ] Commit 后确认文件列表有 web / api / scripts / docs / .github / vercel.json / .env.example / README.md

## 第 3 步：Vercel 部署

- [ ] vercel.com → Add New → Project → Import `aidash-v2`
- [ ] Framework Preset 选 Other；Build Command / Output 留空（vercel.json 已内置构建命令）
- [ ] Environment Variables 添加 9 个：
  - `AI_PROVIDER=deepseek`、`DEEPSEEK_API_KEY=sk-...`、`DEEPSEEK_MODEL=deepseek-chat`
  - `OPENAI_API_KEY`（跳过）、`OPENAI_MODEL=gpt-4o-mini`
  - `GITHUB_TOKEN=github_pat_...`（第 1 步的新 Token）、`GITHUB_REPO=jiejinfeilu/aidash-v2`、`GITHUB_BRANCH=main`
  - `APP_PIN=你的新口令`
- [ ] Deploy，等待成功，记下地址（如 `https://aidash-v2-xxxx.vercel.app`）
- [ ] 验证：打开 `/api/process` 应返回 405；打开根地址 `/` 应看到 AiDash 页面（Vercel 双入口）
- [ ] 修改 `web/config.js` 的 `API_BASES` 为真实地址（或用手机设置页填写）

## 第 4 步：GitHub Actions Secrets

- [ ] 仓库 Settings → Secrets and variables → Actions，添加 6 个：
  - `SMTP_HOST=smtp.qq.com`、`SMTP_PORT=465`、`SMTP_USER=你的QQ邮箱`
  - `SMTP_AUTH_CODE=16位授权码`、`SMTP_FROM=AiDash`、`KINDLE_EMAIL=xuexiheshiyong_TJG39A@kindle.com`
- [ ] Actions → Fetch Hotlists → Run workflow（热榜）
- [ ] Actions → Daily Kindle Push → Run workflow（测试推送，应成功）

## 第 5 步：手机连接 v2

- [ ] 手机打开 `https://jiejinfeilu.github.io/aidash-v2/web/`（或 Vercel 地址）→ 添加到主屏幕
- [ ] 设置 → 连接：后端地址 = Vercel 新地址；数据地址 = `https://raw.githubusercontent.com/jiejinfeilu/aidash-v2/main`；口令 = 新 APP_PIN
- [ ] 设置版式（竖屏/横屏）、每日名言条数、推送间隔，保存到云端
- [ ] 记录页测试 AI 秘书 → 保存 → 确认 v2 仓库出现 data.json
- [ ] 仪表盘 Tab 测试本地生成 / 全屏 / 保存 / 立即刷新

## 第 6 步：停旧版推送 + 验收

- [ ] 旧仓库 `aidash` → Actions → 左侧 Daily Kindle Push → 右边 `⋯` → **Disable workflow**（旧网页/App 继续可用）
- [ ] 验收：
  - [ ] v2 新网页能打开、能记录、能保存
  - [ ] v2 手动 Run 推送成功，Kindle 收到新版仪表盘
  - [ ] 旧仓库不再自动推送（旧网页仍可打开）
  - [ ] 4 小时定时生效（可先设 1 小时测试，再改回 4）

## 可选：迁移旧数据

把旧仓库 `data.json` 的内容复制到 v2 仓库 `data.json`（首次保存前手动上传即可），待办/倒计时/笔记就能带过去。
